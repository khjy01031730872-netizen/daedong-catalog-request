# 대동울타리 카탈로그 신청 폼

**배경(2026-08-27):** 인스타·메타·틱톡 등에서 이메일 주소를 스크래핑해 동의 없이 자동 발송하는
프로그램 요청이 있었으나, 정보통신망법 제50조(사전 동의 없는 광고성 정보 전송 금지, 위반 시
3천만원 이하 과태료) 및 CLAUDE.md 법칙16(비동의 콘택트 마케팅 금지)에 위배되어 대신 이 방식을
채택했다: **방문자가 직접 정보를 남기고 명시 동의하면, 그 순간부터 합법적으로 카탈로그·안내
메일을 보낼 수 있다.**

## 현재 상태

- ✅ 폼 자체는 완성·검증 완료 — 회사명/담당자명/이메일/연락처/관심분야/문의내용 입력 +
  개인정보 수집·이용 동의(필수) → 제출 시 즉시 카탈로그(pptx) 다운로드 + 카카오톡 알림.
  Selenium으로 검증 완료(동의 미체크 시 오류, 정상 제출 시 DB 저장+다운로드 버튼 노출, 콘솔 에러 0건).
- ✅ 사내망 상시 서버로 실행 중: `http://192.168.0.51:8517` (`run_server.ps1`)
- ⚠️ **아직 회사 실제 웹사이트(울타리제조.kr, Wix)에는 연결되지 않았다.** 사내망 서버는
  회사 직원만 접속 가능하고, 실제 홈페이지 방문객(잠재 거래처)은 접근할 수 없다.

## 공개 웹사이트 연결 — 진행 상황 (2026-08-27)

두 경로 모두 착수했다:

1. **Wix API 연동 — 키 대기 중.** 사장님이 "저번에 줬다"고 하셨으나, 시스템 전체(.env·secrets·
   메모 등)를 다시 찾아봐도 저장된 Wix API 키를 찾지 못했다. 1부13팀 2026-08-21 문서에도
   "발급 절차만 확인, 실제 키는 사장님이 직접 발급해야 함(대신 발급 불가)"으로 남아 있어, 아직
   실제로 발급된 적이 없는 것으로 보인다. 재확인 필요.

2. **Streamlit Community Cloud 배포 — 코드 준비 완료, 마지막 클릭만 남음.**
   GitHub 저장소(비공개)에 코드를 올려뒀다: https://github.com/khjy01031730872-netizen/daedong-catalog-request
   Streamlit Cloud는 GitHub 계정으로 로그인해 저장소를 선택하는 절차라 이 부분만은 사람이 직접
   해야 한다(계정 로그인이 필요해 대신할 수 없음):
   1. https://share.streamlit.io 접속 → 기존 GitHub 계정(khjy01031730872-netizen)으로 로그인
   2. "New app" → 저장소 `daedong-catalog-request` 선택, 메인 파일 `app.py` 지정 → Deploy
   3. 배포되면 `https://[임의문자열].streamlit.app` 형태 공개 주소가 생성됨 — 이 주소를 홈페이지에
      버튼으로 연결하면 끝.
   4. ⚠️ 무료 플랜은 SQLite 파일이 재배포 시 초기화될 수 있음 — 실사용 전 데이터 영속성 확인 필요.

둘 다 실행 전 사장님 확인이 필요하다(법칙8 — 10부 소관 웹사이트 작업이라 지휘체계상 총괄 노렌을
거쳐야 함).
