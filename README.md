### ⚠️ 2026-08-27 발견·수정된 치명적 버그 (10부 노렌 실측 재현 → 빈센트 즉시 수정)

10부가 클라우드 배포본을 그대로 재현 검증하던 중, 원래 코드가 `corp-org/notify/kakao.py`를
로컬 PC 경로로 import하도록 돼 있어 Streamlit Cloud(원격 컨테이너, corp-org 폴더 없음)에서는
`ModuleNotFoundError`가 확정 재현됐다. 알림 미발송 + **고객 화면에 파이썬 오류 문구가 그대로
노출**되는 문제였다. **수정 내용:**
- 카카오 알림 대신 **Gmail SMTP(앱 비밀번호)**로 전환 — `notify_email.py` 신규 작성. 카카오
  REST 토큰을 이 앱에 별도로 심으면 refresh_token이 로컬 5개 프로젝트와 갈라져
  2026-08-27에 실제로 터졌던 KOE322 회전 충돌이 재발할 위험이 있어(자세한 내용은
  `notify_email.py` 모듈 docstring 참고) Gmail 정적 앱 비밀번호로 우회했다.
- 알림 이메일 본문에 신청 정보 전체를 담아, `leads.db`가 재배포로 초기화되더라도
  이메일함 자체가 사실상의 백업 기록 역할을 하게 했다.
- 알림 실패 사유는 서버 로그(`print`)로만 남기고, **고객에게는 절대 노출하지 않도록** 수정.
- 로컬 재현 테스트(Selenium, secrets 미설정 상태)로 "알림 실패해도 고객 화면은 깨끗한 성공
  메시지만 보임 + 콘솔 에러 0건"까지 확인 완료.
